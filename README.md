# iiko: рекомендации «берут вместе»

Инструмент для построения таблицы рекомендаций на основе данных о продажах из iiko.
Показывает, какие блюда чаще всего заказывают вместе в одном заказе — это помогает
настроить блок «С этим берут» в меню или киоске.

---

## Как открыть

Сервис доступен по ссылке на Streamlit Cloud (уточни у разработчика).
Открывается в любом браузере — установка ничего не требует.

---

## Как загрузить данные

Есть два способа — на выбор.

### Способ 1 — подключение к iiko Server напрямую (вкладка «🔌 iiko Server»)

1. В поле **URL сервера** введи адрес iiko Server, например:
   ```
   https://название-заведения.iiko.it:443
   ```
2. Введи **Логин** и **Пароль** от iiko Server.
   Пароль передаётся в зашифрованном виде — вводить можно обычный.
3. Выбери период: **Дата с** и **Дата по**.
4. Нажми кнопку **«Загрузить данные с сервера»**.
5. Дождись зелёного сообщения «Получено строк: N» — данные загружены.

> **Совет:** Для получения значимых рекомендаций рекомендуется брать период
> не менее 1–3 месяцев.

---

### Способ 2 — загрузка XML-выгрузки (вкладка «📂 XML файл»)

1. В iiko BackOffice перейди в **Отчёты → OLAP-отчёт по продажам**.
2. Настрой нужный период и нажми **Выгрузить → XML**.
   Файл называется примерно `REPORT_20260101_20260201.xml`.
3. В приложении перейди на вкладку **«📂 XML файл»**.
4. Нажми **Browse files** или перетащи файл в область загрузки.
5. Дождись зелёного сообщения «Распарсил строк: N».

## Настройки (левая панель)

| Параметр | Что делает | Рекомендуемое значение |
|----------|-----------|----------------------|
| **Макс. рекомендаций на блюдо** | Сколько похожих блюд показать рядом с каждым | 8 |
| **Мин. совместных покупок** | Сколько раз два блюда должны встретиться в одном заказе, чтобы попасть в рекомендации | 1 (при малом объёме данных), 2–5 (при большом) |
| **Категории для исключения** | Названия категорий, которые не нужно включать в рекомендации (обычно модификаторы и добавки). По одной строке каждая. | Оставь пустым или укажи нужные категории |

**Пример заполнения поля исключений:**
```
Модификаторы
Добавки
Соусы
```

## Как скачать файл рекомендаций

После загрузки данных внизу страницы появится кнопка:

> **⬇️ Скачать CSV для техподдержки**

Нажми — браузер скачает файл `recommendations_ГГГГ-ММ-ДД.csv`.

### Что содержит CSV

Каждая строка — одна пара «блюдо → рекомендуемое блюдо»:

| Колонка | Описание |
|---------|----------|
| `dish_id` | ID блюда в iiko |
| `dish_name` | Название блюда |
| `category` | Категория блюда |
| `recommended_dish_id` | ID рекомендуемого блюда |
| `recommended_dish_name` | Название рекомендуемого блюда |
| `rank` | Порядковый номер рекомендации (1 = самая популярная пара) |
| `co_occurrence` | Сколько раз эти блюда заказывали вместе |

## Диагностика

Если после загрузки данных появилось сообщение
«По текущим настройкам рекомендаций не получилось» — раскрой блок
**«🔍 Диагностика загруженных данных»**.

**Что смотреть:**

- **Колонки** — должны быть `UniqOrderId.Id`, `DishId`, `DishName`.
  Если их нет — сервер вернул не те данные, обратись к разработчику.
- **Заказов с 2+ разными блюдами** — если `0`, то данные есть, но все заказы
  однопозиционные. Рекомендации строить не из чего.
- Если всё выглядит нормально — попробуй снизить **«Мин. совместных покупок»** до `1`
  или взять более длинный период.

## Типичные ошибки и решения

| Сообщение | Причина | Что сделать |
|-----------|---------|-------------|
| `Ошибка HTTP 400` | Неверные параметры запроса к серверу | Обратиться к разработчику |
| `Ошибка HTTP 401` или `403` | Неверный логин или пароль | Проверить учётные данные iiko |
| `Не удалось подключиться к серверу` | Неверный URL или сервер недоступен | Проверить URL (формат `https://...`) и интернет-соединение |
| `Сервер вернул пустой ключ авторизации` | Нестандартный ответ сервера | Обратиться к разработчику |
| `Не смог распарсить XML` | Загружен не тот файл (например, Excel-выгрузка) | Убедиться что файл — XML-отчёт из iiko, не таблица |
| `Рекомендаций не получилось` | Нет заказов с двумя и более блюдами, или слишком высокий порог | Снизить «Мин. совместных покупок» до `1`, взять более длинный период |
